# icontext-feature-review - OpenAI Codex CLI adapter

Follow `PROCEDURE.md`: pick one `plans/NNN-<slug>/` folder, read its role files and `CR-*.md`, fill
`templates/review-template.md` (requirement view + technical view + cross-checks + verdict), and write
`REVIEW.md` in that folder. Cite the source file/section for every claim; write "not stated in the plan"
instead of guessing. Read-only otherwise: do not edit plans, implement, commit, or push.
